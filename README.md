# 📖 Nossa História

Um livro digital interativo criado para transformar memórias, momentos especiais e lembranças em uma experiência única.

## ❤️ Sobre o Projeto

Este projeto foi desenvolvido como uma forma de registrar uma história especial através de páginas digitais, reunindo fotos, mensagens, datas marcantes e recordações inesquecíveis.

Cada capítulo representa um momento importante dessa jornada, permitindo reviver memórias de maneira simples, bonita e interativa.

## ✨ Recursos

- 📸 Galeria de fotos
- 💌 Mensagens especiais
- 📅 Linha do tempo da história
- 📖 Capítulos personalizados
- 📱 Interface responsiva
- 🎨 Design pensado para uma experiência acolhedora

- JavaScript
